# Issue list redesign: my changes

The current screen is in `getting-sign-off-h1-issue-list.html`. Bug tracker web app, used on desktop and on tablets.

1. **Denser rows.** Row height from 56 px to 44 px, so about 25% more issues fit on screen.
2. **Priority as a dot.** Replace the text label ("High", "Medium", "Low") with a coloured dot (red, amber, grey).
3. **Avatar first.** Move the assignee avatar from the right end of the row to the left of the title.
4. **New issue button.** Move it from the top right of the toolbar to a floating round button at the bottom right, and rename it to "Create".
5. **Updated column.** Remove the "Updated" column; show the date in a tooltip when you hover the row.
6. **Filters.** Collapse the five filter chips (Status, Assignee, Priority, Label, Milestone) into one "Filter" menu.
