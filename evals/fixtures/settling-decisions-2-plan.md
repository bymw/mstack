# Plan: editing recurring events (team calendar)

Batch 1 builds the edit sheet for recurring events. It starts once the decisions table below is filled and the plan is locked.

## Open questions (framed in the last session)

1. When someone edits one event in a weekly series, what do we ask?
   - This event or all events (Recommended): two choices people already know from other calendars.
   - This, following, or all: more control, one more choice on every edit.
   - Always this event only: fastest, but changing the whole series needs a separate setting.

2. When the organiser moves a series, do attendees get one update or one per event?
   - One update for the series (Recommended): one message instead of a flood.
   - One per event: precise, but noisy for long series.

3. Can attendees propose a new time for one event in a series?
   - Not in batch 1 (Recommended): keeps the batch to the organiser's edits; proposals come later.
   - Yes, in batch 1: adds a second flow to design and test now.
