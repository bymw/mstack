# Shared lists: spec summary (Pantrybook, web)

- A list can be shared with up to 10 people by invite link. Everyone can add, edit, check and delete items.
- Changes appear on other open screens within 3 seconds.
- Editing works offline in the browser tab; changes sync when back online.
- Conflict rule: the later change received by the server wins, per field; delete wins over edit.
- Sessions expire after 12 hours of inactivity; the person is asked to sign in again.
- Lists are sorted by the time each item was added.
